
# Habit Tracker

A simple, no-setup habit tracker that runs entirely in your browser. Add habits, check them off each day, and watch your streaks grow.

**Live demo:** https://avagracetrachta-cloud.github.io/habit-tracker/

## Features

- Add and delete habits
- One-click "Mark done" for today
- 7-day grid per habit (click any day to fix a missed check-in)
- Streak counter
- Daily progress bar
- Light and dark mode (follows your system)
- Data saved in your browser with `localStorage`. No account, no server, nothing leaves your device.

## Run it

Download or clone the repo and double-click `index.html`. That's it. There's nothing to install.

## Host it free with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute, your live link appears at the top of that page.

## Built with

Plain HTML, CSS, and JavaScript. One file, no libraries.
