
# Habit Tracker

A simple, no-setup habit tracker that runs entirely in your browser. Add habits, check them off each day, and watch your streaks grow.

## Features

- Add and delete habits
- One-click "Mark done" for today
- 7-day grid per habit (click any day to fix a missed check-in)
- Streak counter
- Daily progress bar
- Light and dark mode (follows your system)
- Data saved in your browser with `localStorage`. No account, no server, nothing leaves your device.

## Run it

Download or clone the repo and double-click `index.html`. Open on browser of your choice & add in your specific habits for the week!

## Built with

Plain HTML, CSS, and JavaScript. One file, no libraries.
